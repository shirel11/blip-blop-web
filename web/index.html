בוחרים דמות, ומתחילים

בתפריט המשחק בחרו Start Game ואז One Player, ואשרו דמות עם Enter או אישור. לחצו שוב כדי להתקדם במסכי הסיפור. אפשר גם לשחק בשניים עם מקלדת אחת.

בנייד: החליקו על משטח הכיוונים והחזיקו את כפתורי הירי והקפיצה באגודל השני. מצב משחק מסתיר את שולי האתר. אפשר לחזור ממנו בכל רגע.

מקלדת ושחקן נוסף

שחקן 1: חצים, Z לירי, X לקפיצה, Space לפצצה. Esc להשהיה. שחקן 2: Q / S / D / F לכיוונים, Tab לירי, G לקפיצה ו־H לפצצה.

האתר תומך בעברית ובאנגלית. התפריטים והסיפור המקוריים בתוך המשחק הם באנגלית.
