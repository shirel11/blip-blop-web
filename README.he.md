# Blip & Blop — גרסת דפדפן

[למשחק](https://shirel11.github.io/blip-blop-web/?lang=he) · [English documentation](README.md)

המשחק הקלאסי בדפדפן, עם מעטפת בעברית ובאנגלית ושליטה במקלדת או במגע. אין צורך בהתקנה או בחשבון.

## משחק בנייד

- הטעינה הראשונה מורידה כ־53MB. מומלץ Wi-Fi.
- אחרי הטעינה לחצו **שחק עכשיו**, בחרו Start Game, שחקן אחד ודמות. כפתור **אישור** משמש גם לתפריטים.
- באייפון עדיף לסובב לרוחב. משטח התנועה נמצא משמאל וכפתורי הפעולה מימין, בלי להסתיר את המשחק.
- אפשר להחזיק תנועה וירי יחד, להחליק בין כיוונים ולקפוץ עם אגודל שני.
- **מצב משחק** מנצל את שטח התצוגה גם אם Safari לא מאפשר מסך מלא דרך הדפדפן.
- השפה מתחלפת בכפתור English / עברית ונשמרת למפגש הבא. הסיפור והתפריטים המקוריים בתוך המשחק הם באנגלית.

## הפעלה ופיתוח

דרוש Node.js בגרסה 20 ומעלה. אין תלות בחבילות npm לבניית האתר.

```sh
git clone https://github.com/shirel11/blip-blop-web.git
cd blip-blop-web
npm run check
npm run build
npm run dev
```

פתחו http://127.0.0.1:8083. הקבצים `web/index.html`,‏ `web/public/app.js` ו־`web/public/app.css` מכילים את ממשק הדפדפן. קוד מנוע המשחק נמצא ב־`port/`.

הוראות מלאות לבנייה מחדש של WebAssembly, תיקיות הפרויקט, פרסום ורישוי נמצאות ב־[README באנגלית](README.md).

## פרסום וקישור

הריפו כולל GitHub Actions לפרסום אוטומטי דרך GitHub Pages בכל דחיפה ל־`main`. הכתובת היא **https://shirel11.github.io/blip-blop-web/**. קישור עם `?lang=he` נפתח בעברית ו־`?lang=en` באנגלית. אפשר לחבר דומיין בבעלותכם דרך הגדרות Pages ו־DNS.
